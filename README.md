# EdgeLite Factory Hub

### Cost-Effective Edge AI & Digital Twin for Smart Shop-Floor Automation

**Hyundai Innovation Challenge 2026**

---

## Overview

**EdgeLite Factory Hub** is a software-based industrial **Edge AI and Digital Twin platform** designed to demonstrate cost-effective shop-floor digitalization without relying on expensive IPC infrastructure for every machine.

The platform combines a virtual **UR5e industrial robot**, local edge processing, AI-based machine monitoring, task scheduling, fault detection, diagnostics, recovery, and automated reporting into a single smart factory environment.
